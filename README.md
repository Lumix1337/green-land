## 🎯 Концепт, Персона и Signature Feature

* **Персона:** **Ерлан, 42 года**, владелец коммерческой теплицы томатов (площадь 800 м²) в пригороде Алматы.
* **Проблема:** До 50% всех эксплуатационных расходов уходит на обогрев и искусственное досвечивание. Разница между дневным (28.50 ₸/кВт⋅ч) и льготным ночным тарифом (11.20 ₸/кВт⋅ч) огромна, но персонал забывает вовремя переключать режимы, сжигая прибыль.
* **Signature Feature:**
  > *«Приложение GreenLand рассчитывает финансовую экономию в тенге и автоматически оптимизирует работу отопления и фитоосвещения по дифференцированным тарифам на электроэнергию и внешнему прогнозу погоды, сберегая до 48 200 ₸ в месяц».*
* **Выбранный трек:** **Resource Savings** (Экономия ресурсов и финансов).
* **Визуальный стиль:** Фирменная палитра GreenLand: глубокий хвойный (`#1B5E20`), изумрудный (`#2E7D32`), мятный акцент (`#4CAF50`), контрастные скругленные карточки, органика.

## 📱 Реализованные экраны и модули ТЗ

Приложение содержит **5 полноценных экранов**, адаптирующихся под любые диагонали экранов:

1. **Экран авторизации (`AuthScreen`) — Модуль M1:**
   * Вход по email и паролю с валидацией.
   * Кнопка быстрого демо-входа для презентации (профиль Ерлана).
   * Изоляция данных теплицы через Row Level Security (RLS).
2. **Главный Дашборд (`DashboardScreen`) — Модули M2, M5, M8:**
   * 4 ключевых параметра: температура воздуха (°C), влажность воздуха (%), влажность почвы (%), освещенность (kLux).
   * Цветовые индикаторы нормы (зеленый / желтый / красный) и прогресс-бары.
   * Время последнего обновления показаний («только что», «15 сек. назад»).
   * Быстрая оценка здоровья теплицы за **$< 5$ секунд** (Сценарий №1 ТЗ).
   * Всплывающий баннер критического перегрева (Сценарий №2 ТЗ).
3. **Пульт дистанционного управления (`ControlScreen`) — Модуль M3:**
   * 4 виртуальных исполнительных механизма:
     - 💧 **Капельный полив** (насос орошения грядок)
     - 🪟 **Вентиляция** (сервопривод фрамуг и окон)
     - 🔥 **Отопление** (тепловентилятор)
     - 💡 **Фитоосвещение** (светодиодные лампы досвечивания)
   * Индикатор времени отклика приборов ($0.8$ с при нормативе ТЗ $<5$ с).
   * Кнопка аварийного выключения всех систем.
4. **Аналитика и Графики (`AnalyticsScreen`) — Модуль M6:**
   * Интерактивные графики влажности почвы и температуры воздуха.
   * Переключение временных периодов: **24 часа** и **7 дней**.
   * Лог событий: точка дефицита влаги (Сценарий №4 ТЗ).
5. **Настройки и Энерго-оптимизатор (`SettingsScreen`) — Модули M4, M7:**
   * Виджет Signature Feature: расчет сэкономленных киловатт и тенге.
   * Ползунки настройки безопасных порогов (старт полива при влажности $<30\%$, открытие окон при $>28^\circ\text{C}$).
   * Переключатель языка: Русский / Қазақша.
   * Тумблер симуляции обрыва связи для демонстрации **стресс-теста комиссии (M8)**.

## 🛡️ Отказоустойчивость и Стресс-тест комиссии (M8)

На защите проекта комиссия намеренно обрывает связь с симулятором или сервером. В GreenLand реализована трехуровневая защита:
1. **Глобальный обработчик ошибок (`FlutterError.onError`):** Приложение никогда не крашится (no red screen of death).
2. **Индикатор «Нет связи» (`StatusBanner`):** При потере сигнала появляется понятный информационный баннер: *«Симулятор отключен. Показаны кэшированные данные. Приложение работает стабильно»*.
3. **Кнопка проверки стресс-теста:** В меню дашборда и настройках доступен мгновенный тумблер симуляции сбоя для демонстрации перед преподавателями.

## 🚀 Инструкция по сборке и запуску

### Требования
* Flutter SDK $\ge 3.0.0$
* Android Studio / VS Code с плагином Flutter
* Android Device или Эмулятор (API $\ge 21$)

### Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Lumix1337/green-land.git
   cd green-land
   ```

2. Установите зависимости:
   ```bash
   flutter pub get
   ```

3. Запустите приложение в режиме отладки:
   ```bash
   flutter run
   ```

4. Сборка готового APK (для сдачи в CP3):
   ```bash
   flutter build apk --release
   ```
   Файл будет сгенерирован по пути: `build/app/outputs/flutter-apk/app-release.apk`.
